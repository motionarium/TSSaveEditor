## [1.2.0] — 2026-07-31

### Добавлено
- Вкладка **Моды** (только просмотр): скан папки `Documents\…\mod`, кэш на диск, списки «все в папке» / «активные в сейве»
- Определение версии игры из `game.log.txt` (ETS2 / ATS) и фильтр совместимых модов
- Автодетект модуля карты из `map_path` + `active_mods` / `dependencies`, сканирование `.scs` / ванили
- Открытие городов карты и тумана (`discovered_items`) с прогресс-баром
- В списках техники: **тип номера** из `license_plate` (часть после `|`, напр. `russia`, `germany`)
- Устойчивое чтение модовых карт: неизвестные item types / битые сектора не роняют весь скан
- Поддержка ZIP-`.scs` наряду с HashFS
- Вендор **TruckLib** в `deps/` для чтения карт

### Изменено
- Раздел **Карта и гаражи** переведён на продвинутый список городов/гаражей без simple/advanced режимов
- **Экономика** и **Техника**: перевёрстка карточек, списки с title/subtitle, секции на высоту окна
- ADR: увеличены вертикальные отступы (как у навыков)
- Подписи модов: Steam Workshop без длинных id, без ложного «нет манифеста» для отсутствующих файлов
- Санитизация имён (`\xNN`, zero-width) в карте и модах
- Фиксированное окно, единый визуальный язык вкладок

### Исправлено
- Падения на модовых картах с неподдерживаемыми типами объектов
- Обрезка длинных подсказок и подписей в UI
- Парсинг версии из актуального формата `game.log.txt` (`init ver.`, `pack set version`, `g_game_version`)

### Сборка
- Framework-dependent single-file `TSSaveEditor.exe` (~5 MB), .NET 8 Desktop Runtime
- GitHub Actions: релиз по тегу `v*`

## [1.1.0] — 2026-07-20

### Добавлено
- Первый публичный релиз TSSaveEditor
- Экономика: деньги, XP/уровень, навыки, ADR
- Карта / гаражи (ранний режим)
- Техника: ремонт и топливо
- Steam / Local профили, SteamID64
- Настройки: язык RU/EN, темы, пути, decryptor
- Проверка обновлений с GitHub
